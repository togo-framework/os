# os — docs

Documentation for the `togo-framework/os` plugin — an OS-style desktop shell for togo apps.

- **Install:** `togo install togo-framework/os`
- **Scaffold an app:** `togo make:os-app <name>`
- **New project on the desktop shell:** `togo new <app> --frontend os`
- **Marketplace:** https://to-go.dev/marketplace
- **Source:** https://github.com/togo-framework/os

See the repository [README](../README.md) for the app registry (`os.RegisterApp`),
`DesktopPrefs`, and the `/api/os/*` endpoints. Add deeper guides here as the plugin grows.
